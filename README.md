# PageFlow AI 📝

PageFlow AI is a lightweight web application designed for indie authors, educators, and content creators. It utilizes Google's Gemini 1.5 Flash model to transform raw, messy notes into structured, print-ready manuscript chapters while maintaining narrative tone and consistency.

### Tech Stack
* **Frontend:** HTML5, Tailwind CSS (via CDN)
* **Backend:** Node.js, Express.js
* **AI Engine:** Google Gemini 1.5 Flash API 
* **Security:** `express-rate-limit` for API protection
* **Deployment:** Vercel (Serverless)

### Features
* Context-aware drafting from raw text inputs.
* Clean, responsive UI with mock Auth and Legal dashboards.
* Built-in rate limiting to prevent API abuse and server overload.
* Configured for seamless serverless deployment on Vercel.
